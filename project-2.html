A unified vinyl record search platform aggregating listings from multiple marketplaces — so collectors and casual listeners can instantly discover availability, condition, and lowest price.

Role: Project Series Member

Project Details

Built with CSS, JavaScript, Node, and React. Solves the frustration of hunting across dozens of marketplaces to find a specific vinyl record.

01Aggregates listings from multiple sites into one destination
02Shows condition info and lowest price per record
03Search by vinyl record, artist, or album
04Account system with favorites and listing views

Technical Stack

React frontend, Node.js backend, CSS for a clean minimal dark-themed UI centered around a single search experience.
